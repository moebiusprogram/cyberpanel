# Moriah.cloud   
**Hosting inteligente para pequeñas y medianas empresas, basado en CyberPanel**

Moriah.cloud es una versión personalizada de CyberPanel, optimizada para ofrecer servicios de hosting ágiles, seguros y escalables a PYMEs. Nuestro enfoque modular permite una gestión eficiente de recursos, automatización de tareas clave y una experiencia de usuario simplificada.

---

##  Características principales

-  Seguridad reforzada con configuraciones predefinidas de firewall y SSL  
-  Panel de control intuitivo con mejoras UX para clientes no técnicos  
-  Instalación automática de WordPress, Joomla y otros CMS populares  
-  Monitorización de recursos en tiempo real  
-  Backups automáticos y restauración simplificada  
-  Integración con herramientas de IA para soporte predictivo *(en roadmap)*  

---


##  Instalación rápida

```bash
git clone https://github.com/moebiusprogram/cyberpanel
cd cyberpanel/install
bash setup.sh
```

> Requisitos: Ubuntu 20.04+, mínimo 2GB RAM, acceso root
